## 2. 优化顺序

### P0：企业开放前必须完成

1. **实名用户与会话**：密码安全哈希、登录、退出、会话过期、即时撤权、用户/角色/scope 管理、认证审计和登录限流。
2. **可观测性闭环**：Prometheus 指标、队列/任务/执行器/磁盘关键指标、告警阈值和 runbook。
3. **迁移与恢复**：生产旧库脱敏副本升级、备份、恢复后一致性和回滚演练。
4. **故障边界**：staging 强杀 Web/executor、Docker split、Chromium 分片故障。
5. **真实平台 canary**：三平台各一条私密/草稿发布、远端终态和重启不重复发布。

### P1：团队正式使用前

1. 企业 SSO 接入；标准 TOTP 双因素已在批次 3 完成代码闭环。
2. 用户禁用后关联会话、未执行任务和子任务的处置策略；代码与自动测试已完成，待 staging 复验。
3. 素材资源级 ACL、导出审批和审计留存清理策略。
4. 容量压测、SLO 看板和异常成本告警。
5. 平台改版适配包发布、回滚和人工兜底演练。

### P2：规模扩展

1. leader election、多 executor、跨主机任务事实库。
2. 对象存储与数据库迁移路径。
3. 多工作区和更细粒度组织数据隔离。

## 3. 当前实施批次

### 批次 1：实名认证与会话

目标：在不破坏现有全局令牌和用户令牌兼容性的前提下，增加数据库用户登录会话。

验收门：

- 密码使用版本化、慢哈希算法，禁止新密码使用无盐 SHA-256。
- 会话令牌只在客户端保存，数据库只保存哈希。
- 会话有过期时间、撤销时间、最后活动时间和客户端元数据。
- 禁用用户或撤销会话后，新请求立即失败关闭。
- 用户、角色、scope 和密码变更由管理员接口执行并写审计。
- 非管理员不能管理用户，业务请求仍受原四角色矩阵约束。
- 登录接口有限流；错误登录不暴露用户是否存在。
- 现有全局令牌和用户令牌继续可用，便于迁移与应急。
- 后端黑盒测试覆盖登录、会话、撤权、角色边界、密码修改和退出。

回滚：认证变更使用增量表结构；必要时关闭 `YUNCE_PERSONAL_AUTH` 并回退代码，数据库新增列和会话表可保留。

## 5. 实施记录

### 2026-11-23：实名认证批次

- 新增 `user_auth.py`：个人密码登录、PBKDF2-SHA256 版本化密码哈希、服务端会话、12 小时过期、会话哈希落库、最多 10 个有效会话、退出、改密、管理员重置密码和强制下线。
- 用户表增加显示名、禁用状态、首次改密、更新时间、密码更新时间和最近登录时间；数据库记录 `named_auth` schema 版本。
- 新增 `cutter`、`reviewer`、`operator`、`admin` 成员管理接口，只有 `team.manage` 可访问；禁止禁用或降级最后一个有效管理员。

- 登录接口默认 10 次/5 分钟限流；错误响应不区分用户不存在、密码错误或账号禁用。
- 前端增加个人登录、旧令牌回退、首次改密、退出登录和「设置 → 团队」管理页。
- 自动测试覆盖密码哈希、登录、哈希落库、无效密码、禁用撤权、退出、改密、角色边界、用户管理和公开配置。

证据等级：**E2**。仍需在真实 Web 进程、反向代理、生产等价用户数据和浏览器中复验。

### 2026-11-23：备份校验批次

- 新增 `deploy/restore_verify.py`，在不覆盖生产目录的临时空间中检查备份压缩包的路径安全、4 个 SQLite 的 `quick_check`、关键表、用户/管理员/孤儿会话、任务数量、环境变量必要键和凭据文件数量。

- 新增自动测试，使用四个合成 SQLite、加密凭据占位文件和环境变量构造压缩包，验证关键计数及恢复前检查。

### 2026-11-23：双因素与持久锁定批次

- 新增标准 TOTP 双因素认证：认证器二维码、手动密钥、首次确认、登录二次验证、验证码重放保护和加密密钥落库。
- MFA 密钥使用现有 AES-256-GCM 凭据主密钥加密，AAD 绑定用户 ID 和登录名；数据库不保存明文 TOTP 密钥。
- 双因素登录挑战默认 5 分钟过期、最多 5 次失败、绑定发起 IP，且同一验证码时间步不能重复使用。
- 新增持久化登录失败锁定：用户名和 IP 分别累计，默认用户 10 次失败锁定 15 分钟、IP 60 次失败锁定 15 分钟；管理员可解除用户锁定。
- 新增「设置 → 安全」页面，成员可自行绑定或关闭认证器；团队页支持管理员重置 MFA 和解除登录锁定。
- 指标和认证状态增加 MFA 用户数、锁定账号数；OpenAPI、部署变量、运维手册和恢复说明同步更新。
- 自动测试覆盖 TOTP 绑定、二次登录、验证码重放拒绝、持久锁定、管理员解锁和权限边界。

证据等级：**E2**。仍需在真实浏览器、手机认证器和反向代理环境完成端到端复验；企业 SSO 仍是后续增强。

当前工作区 `db/database.db` 已通过 SQLite backup API 复制到临时文件并执行 `named_auth` schema 升级：`quick_check=ok`，旧 `users` 表原地补齐 MFA/禁用/更新时间列，`auth_login_failures` 与 `mfa_challenges` 正常创建。该结果证明当前本地真实 schema 的升级路径可用，但仍需使用脱敏生产旧库副本在 staging 复验。
