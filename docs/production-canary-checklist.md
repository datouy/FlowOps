# 云策 FlowOps 生产 canary 与故障演练清单

> 目标：取得真实平台和故障恢复的 E3/E4 证据。未完成本清单前，只能标记“待生产验收”。

## 1. 前置条件

- [ ] 使用独立 staging 域名、独立 `data/` 目录和专用测试账号。
- [ ] 测试账号已获授权，内容不涉及真实客户隐私或外部群发。
- [ ] 发布可见性设为草稿或私密；禁止默认公开发布。
- [ ] 已完成数据库、环境变量、Cookie 和审计表备份。
- [ ] Web 与 executor 使用同一份 SQLite 数据卷，当前只运行一个生产 executor。
- [ ] 记录版本、镜像 ID、Git 提交、启动时间、账号、代理出口和时区。
- [ ] 管理员使用个人账号；记录操作人、测试账号和账号 scope。
- [ ] 在平台侧确认该测试账号允许删除或隐藏验证作品。

## 2. 单个平台 canary

每个平台至少执行一次，三条全部通过后才算该平台本轮通过。

### 抖音

- [ ] 扫码登录，刷新页面后仍可识别账号。
- [ ] 使用唯一测试标题、私有/草稿可见性和专用素材提交一条任务。
- [ ] 验证任务进入 executor、产生 job/item 事件，CPU/内存无异常增长。
- [ ] 从创作者后台获取远端作品 ID、状态、可见性和页面截图。
- [ ] 系统回写 `remote_id` 和真实终态；无法回查时只允许 `submitted`/`uncertain`。
- [ ] 重启 Web 和 executor 后，不创建第二条同幂等键作品。

### 小红书

- [ ] 使用主站与创作服务平台实际可操作的测试账号扫码。
- [ ] 验证账号平台身份、私信归属和发布身份一致，不串号。
- [ ] 提交唯一私有/草稿 note，等待平台处理并记录 note ID、状态、截图。
- [ ] 模拟选择器临时不可见，确认失败进入人工处理而不是伪成功。
- [ ] 重启后确认登录态、任务状态和远端 ID 保持。

### 视频号

- [ ] 验证微信/视频号账号、频道和本地 profile 谱系一一对应。
- [ ] 提交唯一私密/草稿视频，记录远端作品 ID、频道和状态。
- [ ] 检查代理、指纹、Cookie 和频道名称没有串用。
- [ ] 重启 Web/executor 后确认频道身份和登录态保持。
- [ ] 确认执行器不会对该已提交作品自动重复发布。

## 4. 强杀恢复演练

### Web 强杀

1. 保持 executor 正在处理一条私有 canary。
2. 强制终止 Web，记录时间、job/item 和租约。
3. 重启 Web，检查 API、个人登录、`/health/ready` 和审计日志。
4. 确认 executor 未被误领或重置，任务最终状态可追溯。

### Executor 强杀

1. 在任务执行中强制终止 executor。
2. 等待租约过期，确认 restart 后只回收无有效租约任务。
3. 已提交但未知的 item 必须进入 `uncertain`，不得自动重发。
4. 人工核对远端后再回写成功或创建替代任务。

### Chromium 分片故障

1. 记录账号到分片的稳定映射。
2. 定向终止一个 Chromium 分片。
3. 确认其他分片继续工作，崩溃分片按需重建。
4. 受影响账号不得伪成功或重复发布；记录恢复时间。

## 5. Docker split 验收

- [ ] `docker compose ... config` 解析成功。
- [ ] `yunce` 角色为 `web`，`yunce-executor` 角色为 `executor`。
- [ ] 两容器镜像 ID 相同，共享同一数据卷。
- [ ] Web `/health/ready` 能看到 executor 心跳。
- [ ] `deploy/verify_split.sh` 通过。
- [ ] 容器重启后数据、登录态、队列和审计保持。
- [ ] 日志分别落在 `logs/web/` 和 `logs/executor/`。

## 6. 容量基线

建议首轮：3 个专用账号、30 个独立 item（每平台 10）、2 个 worker、2 个浏览器分片；预热 5 分钟，稳定运行至少 60 分钟，重复 3 次。

必须记录：

- 队列等待、浏览器提交阶段和远端终态阶段分别的 P50/P95/max。
- 成功、失败、uncertain 数量和比例。
- 峰值积压、executor 心跳、容器内存、Chromium 分片 RSS 和崩溃次数。
- 平台、账号、素材大小和可见性分组。
- all 与 split 的同口径结果。

没有样本量、分组和时间窗口的单个平均值不能作为容量结论。

## 7. 上线判定

- **通过**：所有 P0 权限、实名会话、备份恢复、split、强杀和三平台真实私密/草稿 canary 有证据。
- **有条件通过**：仅剩非阻断增强；必须有负责人、截止时间、人工兜底和观察期。
- **不通过**：存在重复发布、越权、无法恢复、登录态串号、没有远端证据或 backup 不可恢复。
