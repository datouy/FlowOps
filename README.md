# 云策 YunCe

> 多平台内容运营中枢：把账号、素材、文案、审核、发布、消息和数据复盘汇到一处。

## 项目定位

云策是一个面向国内新媒体运营的开箱即用工具，覆盖抖音、快手、视频号、小红书、微博、百家号六个平台。它不是单一的“群发脚本”，而是围绕运营日常工作流，提供从内容生产到发布复盘的一体化工作台。

本项目基于开源项目 **[dreammis/social-auto-upload](https://github.com/dreammis/social-auto-upload)** 进行二次开发。原项目提供了成熟的多平台浏览器自动化上传能力，云策在此基础上新增了 AI 文案、内容包、合规检查、任务队列、审核流、消息中心、数据回流、运营周报等运营功能。

## 新增功能

### 内容生产

- **AI 文案生成**：按平台风格生成标题、正文、话题和发布建议；默认使用通用模板，并支持餐饮美食、美妆个护、教育培训、健身运动、本地生活、电商零售、房产家居等常见行业及自定义行业。
- **多平台内容包**：一次输入行业和主题，生成 6 个平台的差异化内容；支持后台任务、实时进度、24 小时缓存，AI 接口不可用时自动使用本地模板兜底。
- **自动封面**：从视频首帧生成 3:4 和 9:16 封面。
- **发布前合规检查**：检查标题长度、绝对化用语、联系方式、外链、话题数量、素材和封面要求。

### 发布与审核

- **后台任务队列**：发布立即入队，不阻塞页面。
- **失败自动重试**：失败自动重试一次，并记录完整失败原因。
- **发布记录**：记录平台、账号、素材、状态、错误原因和时间。
- **定时发布与发布日历**：按天查看排期，支持周历视图。
- **智能排期建议**：根据历史作品表现推荐发布时间，并提示撞车。
- **团队审核流**：内容可先提交审核，通过后才进入发布队列。

### 账号与数据

- **多账号管理**：支持扫码登录、登录态保存和有效性巡检。
- **账号过期提醒**：登录失效后在发布记录页和今日待办中提示。
- **数据回流**：抓取平台后台作品播放、点赞、评论等数据。
- **手工关联**：自动匹配失败时，可把平台作品手动关联到发布记录。
- **运营周报**：汇总发布量、成功失败、播放、互动和最佳内容，支持复制和 CSV 导出。
- **异常通知**：发布失败、账号过期、AI 内容包失败可推送到企业微信机器人、飞书机器人或通用 webhook。

### 运营协作

- **统一私信工作台**：按平台、账号、用户聚合会话，识别购买意向并提取规格、预算、时间、公司、联系方式等线索；支持自定义关键词规则、标签、跟进阶段、备注与 CSV 导出。
- **自动回复引擎**：按客群、关键词、平台和优先级匹配规则，支持冷却时间、每日上限、发送时段、评论开关、转人工词、AI 兜底与单客只回一次。
- **自动回复状态**：明确区分“已通过连接器发送”“待人工发送”和“发送失败”，不会把未发出的回复伪装成已送达。
- **私信 Webhook 接入**：通过 `/dm/inbound` 接收平台侧私信事件，支持接入密钥、消息幂等去重和发送连接器回调。
- **抖音私信本地同步（只读）**：使用本机 Playwright 和已保存的抖音登录 Cookie，定时读取创作者中心私信列表；不点开会话、不标记已读，命中的自动回复只生成“待人工发送”。
- **今日运营待办**：汇总待回复、失败发布、待审核、定时任务、账号过期和数据同步提醒。
- **素材标签与去重**：按标签筛选素材，MD5 检测重复文件，显示发布状态，并支持按未使用天数清理。
- **日志轮转**：按 10MB 自动轮转，保留 14 天。

### 私信自动回复怎么接

在「私信中心 → 自动回复规则」里设置总开关、发送时段、关键词规则和连接器。外部系统把新私信 POST 到：

```text
http://127.0.0.1:5409/dm/inbound
```

示例：

```json
{
  "platform": "抖音",
  "account": "你的账号名",
  "external_user_id": "平台内稳定用户ID",
  "external_message_id": "平台内消息ID",
  "author": "王姐",
  "msg_type": "dm",
  "content": "这个产品有哪些规格？多少钱？可以预约吗？",
  "source_content": "产品介绍视频"
}
```

`external_user_id` 用于合并同一客户，`external_message_id` 用于防止重复回复。若在设置中填写了接入密钥，请求需带 `X-YunCe-Secret` 请求头。

自动回复命中后会生成一条回复：

- 未配置“发送连接器”时，状态为「待人工发送」，可在会话中复制；
- 配置连接器后，系统会把回复 POST 到连接器，并按返回结果标记「已发送」或「失败」；
- 平台没有面向个人开放的统一私信发送 API，真实发送需要你自己的合规连接器，云策不绕过平台风控。

### 抖音创作者中心私信本地同步

在「私信中心 → 自动回复规则 → 抖音私信本地同步」中可以开启定时同步、选择抖音账号、设置同步间隔和同步范围，也可以点击「立即同步」。

- 同步器使用本机 Playwright 和账号管理中保存的抖音 Cookie，读取创作者中心网页版当前展示的私信列表。
- 只处理对方发来的文本私信，不处理群聊、自己发出的消息、视频/分享卡片、撤回消息和平台占位提示。
- 新消息复用 `/dm/inbound` 的同一入库逻辑，触发客群识别、规则回复和线索沉淀。
- 首版固定为只读模式：不点开会话、不调用抖音发送接口；即使配置了「发送连接器」，自动回复也只保存为「待人工发送」。
- 默认只同步近 48 小时有更新的会话，并忽略重复消息。可在会话工作台继续人工核对和复制回复。

该方案依赖抖音创作者中心网页版结构。平台改版可能导致选择器失效，需要维护 `douyin_dm_sync.py`。平台未在网页版展示的私信（包括受陌生人私信限制的消息）也无法被适配器读取。

## 快速开始（Windows）

### 环境要求

- Python 3.10+（建议 3.12）
- Node.js 18+
- Windows 10/11

### 安装

```powershell
python -m venv venv
venv\Scripts\pip install -r social-auto-upload-main\requirements.txt
venv\Scripts\python -m playwright install chromium

cd social-auto-upload-main\sau_frontend
npm install
cd ..\..
```

### 配置 AI

复制配置模板并填入自己的 API Key：

```powershell
Copy-Item social-auto-upload-main\.env.example social-auto-upload-main\.env
notepad social-auto-upload-main\.env
```

`.env` 已被 `.gitignore` 排除，不会进入仓库。异常通知可在同一文件中配置：

```text
OPS_WEBHOOK_URL=你的企业微信/飞书机器人地址
OPS_WEBHOOK_TYPE=auto
```

### 启动

双击根目录的 `start.bat`。脚本会自动：

1. 检查 5409 / 5173 端口；
2. 启动 Python 后端；
3. 启动 Vue 前端；
4. 打开 http://localhost:5173。

也可以分别运行 `run_backend.bat` 和 `run_frontend.bat`。

## 安全说明

- `.env`、数据库、Cookie、日志、上传素材、虚拟环境和前端构建产物均不进入仓库。
- 数据库首次启动会自动建表；账号登录态请在本机重新扫码生成。
- 请仅操作自己拥有或获授权的账号。
- 本项目通过浏览器自动化模拟人工操作，平台没有面向个人开放的统一发布 API。请遵守各平台用户协议，控制发布频率。
- AI 生成内容需要人工复核，尤其是价格、库存、效果、服务承诺和广告用语。

## 已知边界

- 平台页面改版可能导致自动化选择器失效，需要跟随上游或本仓库更新。
- 微博、百家号的数据回流和定时能力受平台后台限制。
- 抖音网页版私信同步只读取创作者中心实际展示的会话；陌生人私信是否展示仍受平台规则限制。
- 私信自动发送仍需自建合规连接器；本地同步首版只生成“待人工发送”，系统本身不直接绕过平台风控。
- 真实发布、扫码登录需要在你的本机账号环境中验证。
